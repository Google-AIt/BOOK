# إرشادات التصميم الفني (Design Guidelines) 📐
## شجرة الحياة – خيركم لأهله

يحتوي هذا المستند على القواعد الهندسية للشبكات والمسافات والظلال لضمان تناسق الواجهات الرقمية.

---

## 1. مسافات الهوامش والشبكة (Grid & Spacing System)
نعتمد على شبكة مسافات تعتمد مضاعفات الـ `8px` لضمان محاذاة رياضية نظيفة تشبه معايير Apple و Material Design:

| التسمية | القيمة (Pixels) | الاستخدام الأساسي |
| :--- | :--- | :--- |
| `space-xxs` | `4px` | المسافة بين الأيقونة والنص داخل الأزرار الصغيرة. |
| `space-xs` | `8px` | الفراغ الداخلي للحقول الصغيرة، الفواصل بين البطاقات الفرعية. |
| `space-sm` | `12px` | الهوامش الداخلية لبطاقات الأوراق، وتباعد حقول النماذج. |
| `space-md` | `16px` | حشوة خلايا الجداول، وهوامش البطاقات المتوسطة. |
| `space-lg` | `24px` | الحشوة الداخلية لبطاقات لوحة التحكم الكبرى (Widgets). |
| `space-xl` | `32px` | تباعد العناوين والأقسام داخل لوحة التحكم. |
| `space-xxl` | `48px` | تباعد شبكة صفحة الهبوط والتخطيط الخارجي الكلي. |

---

## 2. نظام الظلال والعمق البصري (Shadow & Elevation)
لمنح الواجهة طابعاً فاخراً مثل ورق الكتان الفاخر المعلق، نستخدم مستويين من الظلال:

- **الظل الورقي الناعم (Paper Shadow):**
  - الاستخدام: للبطاقات الصغيرة والأزرار المستقرة.
  - الكود: `box-shadow: 0 10px 30px rgba(43, 45, 47, 0.06);`
- **الظل الفاخر المرتفع (Luxury Shadow):**
  - الاستخدام: للوحات الكبرى، النوافذ المنبثقة، وصناديق التصدير.
  - الكود: `box-shadow: 0 20px 50px rgba(63, 74, 59, 0.12);`
- **التأثير المذهب (Gold Glow):**
  - الاستخدام: لإبراز الأوراق الذهبية والنوافذ النشطة.
  - الكود: `box-shadow: 0 0 15px rgba(212, 175, 55, 0.3);`

---

## 3. تصميم الأسطح الزجاجية (Glassmorphic Surfaces)
لبناء شعور بالحداثة والأناقة، نستخدم زجاجاً مشوشاً مع حواف مذهبة دقيقة:
```css
background: rgba(255, 255, 255, 0.85);
backdrop-filter: blur(12px);
-webkit-backdrop-filter: blur(12px);
border: 1px solid rgba(232, 223, 216, 0.5);
```
