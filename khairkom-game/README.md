# 🏡 رحلة خيركم - لعبة التقييم والتطوير الأسري الرقمي التفاعلي

منصة رقمية تفاعلية بالكامل باللغة العربية (RTL) مصممة بأسلوب الألعاب (Gamification) لتوجيه وتقييم مشاركة الزوج وتطوير جودة الحياة الأسرية عبر 5 أبعاد رئيسية. الواجهات مستوحاة من فلسفة آبل الإنسانية وتصميمات Headspace و Duolingo المبهجة.

---

## 🌟 مميزات اللعبة

1. **لعبة بناء منزل السعادة (House Builder)**:
   تبدأ الزوجة بقطعة أرض خالية ومنزل غير مكتمل. كل محور يتم إكماله بنجاح يبني جزءاً من المنزل برسوم متحركة جذابة (بتقنية SVG):
   - **المحور 1**: الجدران والأساسات.
   - **المحور 2**: الحديقة ومنطقة ألعاب الأبناء.
   - **المحور 3**: المرآب والبوابة المالية (النفقات).
   - **المحور 4**: الباب الرئيسي والنوافذ (الروابط الاجتماعية).
   - **المحور 5**: السقف والمدخنة والقلوب العائمة (التوافق العاطفي).

2. **عجلة المكافآت التفاعلية (Reward Spin Wheel)**:
   عند إتمام كل محور، تظهر عجلة المكافآت لتدور بشكل تفاعلي وتمنح مكافآت وجوائز تدريبية وتشجيعية.

3. **الذكاء الاصطناعي المتكامل (Gemini AI Engine)**:
   - تحليل فوري بعد كل سؤال وتوليد نصيحة زوجية مكثفة.
   - فقرة إرشاد كوتشينج (Coaching) مخصصة بعد نهاية كل محور.
   - تقرير نفسي وتطويري كامل مع خطة عمل (Roadmap) من 4 خطوات بعد إنهاء الـ 78 سؤالاً كاملة.
   - *ملاحظة*: تم تزويد التطبيق بـ **محرك تحليل محلي تلقائي (Offline Engine)** يعمل فوراً بدون إنترنت أو مفتاح برمجي لتوفير تجربة فورية ممتازة، ويمكن تفعيل الذكاء الاصطناعي الحي من خلال زر الإعدادات العلوي وإدخال مفتاح Gemini API.

4. **نظام النقاط والعملات والتحفيز**:
   - نقاط خبرة (XP)، نجوم (Stars ⭐)، وقلوب (Hearts ❤️) تُمنح بعد كل إجابة.
   - سلاسل إنجازات (Streaks) متتالية تمنح ألقاباً تحفيزية.
   - تحديات أسرية يومية متجددة وتفاعلية لترجمة النصائح إلى سلوك يومي.
   - سجل داخلي لحفظ التقييمات السابقة ومقارنة نسب السعادة بمرور الوقت.

5. **الشهادة التقديرية الفاخرة**:
   - توليد شهادة مذهبة مصممة بخط عربي فني تحمل اسم الزوجة المستعار، تاريخ التقييم، النسبة المئوية المحققة، ورمز QR للتحقق، وجاهزة للطباعة والتنزيل مباشرة.

## 🚀 كيفية التشغيل والبدء

التطبيق مصمم بصيغة **تطبيق صفحة واحدة تفاعلي (SPA)** حديث ولا يحتاج إلى أدوات بناء معقدة أو خوادم تشغيل.

1. **التشغيل المباشر**:
   قم بفتح الملف `index.html` في أي متصفح حديث (Chrome, Safari, Edge, Firefox) بالنقرة المزدوجة مباشرة!
   
2. **عبر خادم محلي (اختياري)**:
   لتفعيل تكامل Gemini API بأمان، يفضل فتح المجلد على خادم محلي. إذا كنت تستخدم VS Code، يمكنك الضغط على زر **Live Server**، أو عبر سطر الأوامر:
   ```bash
   npx serve .
   ```

## ⚙️ إعداد الذكاء الاصطناعي (Gemini API)

لتجربة التقرير الذكي المخصص من جوجل جميناي:
1. اذهب إلى [Google AI Studio](https://aistudio.google.com/) واحصل على مفتاح API مجاني.
2. افتح اللعبة واضغط على أيقونة **الترس (⚙️)** في أعلى اليمين.
3. ألصق المفتاح في خانة المخصصة واضغط **حفظ الإعدادات**.
4. سيقوم التطبيق الآن بمخاطبة الذكاء الاصطناعي لتوليد نصائح وتحليلات حية مصممة خصيصاً لإجاباتكِ!

## 🛡️ هيكلية قواعد البيانات والإنتاج (Firebase Firestore Architecture)

التطبيق مهيأ بالكامل للانتقال إلى الإنتاج والربط بقاعدة بيانات سحابية مثل Firebase. البيانات المهيأة للحفظ متوفرة داخل كائن الحالة `this.state` في الملف `app.js`.

### مقترح الجداول/المجموعات (Firestore Collections):
1. **Users**:
   - `uid` (معرف المستخدم)
   - `username` (الاسم المستعار)
   - `avatar` (الأفاتار المختار)
   - `xp`, `stars`, `hearts` (مجموع الإحصائيات)
   - `unlockedBadges` (الأوسمة المفتوحة)

2. **Assessments**:
   - `assessmentId` (معرف التقييم)
   - `userId` (مرتبط بالمستخدم)
   - `date` (التاريخ والوقت)
   - `overallScore` (النسبة الإجمالية)
   - `answers` (مصفوفة الإجابات المفصلة للـ 78 سؤالاً)
   - `reportMarkdown` (التقرير النهائي المولّد بالذكاء الاصطناعي)
